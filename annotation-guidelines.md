Sentiment Analysis — Annotation Guidelines
Project Objective
The objective of this project is to classify customer reviews according to the sentiment expressed in each statement.
Each review must receive one of three labels: Positive, Negative, or Neutral.
Annotation Labels
Positive: Use this label when a customer expresses happiness, satisfaction, approval, or a positive experience.
Example: “I love this product. It works perfectly!”
Negative: Use this label when a customer expresses disappointment, dissatisfaction, frustration, or a negative experience.
Example: “The delivery was late and the package was damaged.”
Neutral: Use this label when a customer provides information without expressing a clear positive or negative opinion.
Example: “The product arrived yesterday.”
Annotation Rules
Read the entire customer review before assigning a label.
Focus on the sentiment expressed, not just individual words.
Assign only one sentiment label to each review.
Do not assume a customer is happy or unhappy without evidence in the text.
Use Neutral when there is no clear positive or negative sentiment.
Provide a short explanation supporting each label.
Quality Control
Before submitting the annotated data:
Confirm that every review has a label.
Check that each label matches the meaning of the review.
Ensure explanations support the assigned labels.
Check for spelling and formatting errors.
Use the same labeling rules consistently.
Project Scope
This is a beginner practice project using five fictional customer reviews.
The purpose is to demonstrate basic sentiment classification, annotation consistency, and quality control.
