Text Data Annotation — Sentiment Analysis

About This Project

This beginner portfolio project demonstrates text data annotation through sentiment analysis of fictional customer reviews.

The objective is to classify each review as Positive, Negative, or Neutral using consistent annotation guidelines.

Annotation Categories

* Positive: Expresses satisfaction, happiness, or approval.
* Negative: Expresses dissatisfaction, disappointment, or frustration.
* Neutral: Contains no clear positive or negative opinion.

Project Activities

1. Classified five fictional customer reviews.
2. Recorded sentiment labels in Google Sheets.
3. Created annotation guidelines.
4. Reviewed another annotator’s labels for accuracy.
5. Identified and corrected annotation errors.

Quality Control

A five-question quality-control exercise was completed with a score of 5/5.

The exercise tested the ability to identify incorrect sentiment labels and apply annotation guidelines consistently.

Skills Demonstrated

* Text data annotation

* Following annotation guidelines
* Quality assurance
